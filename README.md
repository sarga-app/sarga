# sarga

A self-hosted music server I'm building for myself.

The idea is simple: own your music library, curate it properly, and play it back without the file ever being touched on the way out. No transcoding by default, no compression on the lossless path, no streaming service in the loop.

Written in Go, single binary, Postgres for metadata. Speaks the OpenSubsonic API so existing mobile apps (Symfonium, play:Sub, Tempo, etc.) work out of the box.

## Status

Very early. Nothing works yet. I'm building it in phases and writing things down as I go.

## Why "sarga"

A sarga is a chapter in a Sanskrit epic. Felt right for something organised around albums and discographies.
